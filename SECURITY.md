# Security

Maestro runs inside Claude Code as a hooks module and a skill.

- **The plugin's own hooks** (the `/maestro-stage` panel) only observe tool calls: they never block or rewrite them. To show the branch and its state they run read-only `git` commands (`status`, `rev-parse`, `rev-list`, `branch --list`, `for-each-ref`, `grep`) and `uname -m`, and read files under `.claude/`. They make no network request and never run `git fetch`.
- **The hooks generated by `/maestro` in your project** are plain files under `.claude/hooks/`, listed in the proposal you validate and readable before you commit them. They can refuse tool calls (destructive git and shell commands, edits outside an agent's partition, the opt-in rules), they rewrite an edited file only to restore its line endings and BOM, and the optional work item hook runs the tracker command you configure. The generated `settings.json` raises `BASH_MAX_TIMEOUT_MS` to 30 minutes for long builds. See "What the generated hooks do" in the [plugin README](https://github.com/Jpi-net/maestro/blob/main/plugin/README.md).

To report a vulnerability, open a [private security advisory](https://github.com/Jpi-net/maestro/security/advisories/new) instead of a public issue.
