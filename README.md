# Maestro

[![CI](https://github.com/Jpi-net/maestro/actions/workflows/ci.yml/badge.svg)](https://github.com/Jpi-net/maestro/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

<img src="plugin/assets/icon.png" alt="Maestro icon" width="128">

**Conduct Claude Code like an orchestra.** Maestro sets up a repository so that the main thread plans and delegates, model-tiered experts work in parallel, verification mirrors CI and history stays clean. `/maestro-stage` then shows that flow live in a side panel.

## Install

```
/plugin install maestro --marketplace Jpi-net/maestro
```

or from a shell:

```bash
claude plugin install maestro --marketplace Jpi-net/maestro
```

Full documentation: [plugin/README.md](plugin/README.md).

## Repository layout

- `plugin/`: the plugin, the only part that is published.
- `.claude/`: the development setup generated by maestro on itself (not shipped).
- Tests run with `claude plugin test plugin`.
